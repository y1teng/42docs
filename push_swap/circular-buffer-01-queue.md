# 01. キューとは何か

## まず問題

キューは「先に入れたものが先に出る」構造。

レジの列で考える。

```text
A B C
^
先頭
```

Aが先に並んでいるので、最初に出るのはA。

## 実験

まだコードは書かない。

次の状態を考える。

```text
A B C
```

ここで1回取り出す。

## 観察

残るのはこう。

```text
B C
```

Aはもう取り出された。

## 考察

キューで必要なのは、少なくとも2つ。

- 次に取り出す場所
- 次に入れる場所

この2つを変数で持つ。

```text
head : 次に取り出す場所
tail : 次に入れる場所
```

## 解説

キューは、配列の中身そのものよりも、`head` と `tail` の位置で状態を管理する。

## 今回学んだこと

- キューは先入れ先出し
- `head` は次に取り出す場所
- `tail` は次に入れる場所
