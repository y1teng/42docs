# 05. pop を作る

## 問題

次の関数を書く。

```c
char    pop(t_queue *q);
```

## 機能

キューの先頭から1文字取り出して返す。

## 前提

- `q` は初期化済み
- データは1個以上入っている
- まだ循環処理は考えない
- まだ空判定は考えない

## 最初に間違えやすい実装

```c
char    pop(t_queue *q)
{
    return (q->data[0]);
}
```

これは「0番目を読むだけ」。

でも、取り出す場所は常に0番とは限らない。

## 実験

```c
push(&q, 'a');
push(&q, 'b');
push(&q, 'c');

printf("%c\n", pop(&q));
printf("%c\n", pop(&q));
```

## 観察

期待する動き。

```text
a
b
```

1回目は `head = 0` のデータを返す。

2回目は `head = 1` のデータを返す。

## 考察

`pop()` がすることは2つ。

1. `head` の位置から読む
2. `head` を次へ進める

## 解説

学習中は、短く書きすぎない。

```c
char    pop(t_queue *q)
{
    char    value;

    value = q->data[q->head];
    q->head++;
    return (value);
}
```

こう書くと、途中で `printf()` を入れて確認しやすい。

## 今回学んだこと

- `pop()` は `head` の位置から読む
- 読んだ後に `head` を進める
- `pop()` は中身を消す操作ではない
- 「取り出したことにする」ために `head` を進める
