# 11種類の操作

スタック `a` と `b` を操作できるコマンドは11種類。これがこのプロジェクトで唯一使える「命令セット」。

## swap 系（先頭2要素の入れ替え）

| コマンド | 効果 |
|---------|------|
| `sa` | スタック a の先頭2要素を入れ替える |
| `sb` | スタック b の先頭2要素を入れ替える |
| `ss` | `sa` と `sb` を同時に行う |

```
[2, 1, 3]  --sa-->  [1, 2, 3]
```

要素が1個以下の場合は何もしない。

## push 系（要素の移動）

| コマンド | 効果 |
|---------|------|
| `pa` | b の先頭を a の先頭に移動（b が空なら何もしない） |
| `pb` | a の先頭を b の先頭に移動（a が空なら何もしない） |

```
a: [2, 1, 3]   --pb-->   a: [1, 3]
b: []                    b: [2]
```

## rotate 系（先頭を末尾に送る）

| コマンド | 効果 |
|---------|------|
| `ra` | a の先頭要素を末尾に移動 |
| `rb` | b の先頭要素を末尾に移動 |
| `rr` | `ra` と `rb` を同時に行う |

```
[2, 1, 3, 6]  --ra-->  [1, 3, 6, 2]
```

## reverse rotate 系（末尾を先頭に送る）

| コマンド | 効果 |
|---------|------|
| `rra` | a の末尾要素を先頭に移動 |
| `rrb` | b の末尾要素を先頭に移動 |
| `rrr` | `rra` と `rrb` を同時に行う |

```
[2, 1, 3, 6]  --rra-->  [6, 2, 1, 3]
```

## 操作コスト

`rr` は `ra` と `rb` を1操作で行える。a と b を同時に動かしたいときは積極的に使う。

## 簡単な例（6要素）

```
Init:
  a: [2, 1, 3, 6, 5, 8]  b: []

sa        →  a: [1, 2, 3, 6, 5, 8]
pb pb pb  →  a: [6, 5, 8]    b: [3, 2, 1]
ra rb (=rr) → a: [5, 8, 6]  b: [2, 1, 3]
rra rrb (=rrr) → a: [6, 5, 8]  b: [3, 2, 1]
sa        →  a: [5, 6, 8]
pa pa pa  →  a: [1, 2, 3, 5, 6, 8]  b: []
```

合計12操作でソート完了。
