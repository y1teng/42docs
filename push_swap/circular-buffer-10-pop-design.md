# 10. pop の返り値をどうするか

## 問題

`pop()` は今こう。

```c
char    pop(t_queue *q);
```

でも、空だったら返す文字がない。

C言語では、`char` を返す関数は必ず `char` を返さなければならない。

では、空のときはどうするか。

## 案1: '\0' を返す

```c
if (is_empty(q))
    return ('\0');
```

### 問題点

`'\0'` も普通の `char` データとして使える。

例えば、

```c
push(&q, '\0');
```

したい場合、

- 本物のデータとしての `'\0'`
- 空を表す `'\0'`

が区別できない。

## 案2: 何もしないで終了する

```c
if (is_empty(q))
{
    fprintf(stderr, "queue is empty\n");
    exit(1);
}
```

学習用なら分かりやすい。

でも、関数を使う側からすると強すぎる。

## 案3: 関数の形を変える

```c
int pop(t_queue *q, char *out);
```

成功したら `1` を返す。

失敗したら `0` を返す。

取り出した文字は `out` に入れる。

```c
int pop(t_queue *q, char *out)
{
    if (is_empty(q))
        return (0);
    *out = q->data[q->head];
    q->head = (q->head + 1) % q->size;
    return (1);
}
```

使う側。

```c
char    c;

if (pop(&q, &c))
    printf("%c\n", c);
else
    printf("empty\n");
```

## 考察

最初に

```c
char    pop(t_queue *q);
```

と決めると、空のときに困る。

この疑問は重要。

これは「関数をどう使ってもらうか」の話。

抽象的な言葉を使うならAPI設計とも言うが、今はこう考えればよい。

```text
この関数、失敗したときどうする？
```

## 今回学んだこと

- `char pop()` は空のときに困る
- `'\0'` をエラー扱いすると、本物の `'\0'` と区別できない
- 成功・失敗を返り値で表す形にすると扱いやすい
- 関数を書くときは「失敗したときどうするか」も考える
